# 🥬 Cải Xanh Học MAS (MAS202 - Chapters 5 to 9)

Trang web học tập và ôn thi toàn diện môn Xác suất Thống kê MAS202 từ Chương 5 đến Chương 9:
- **Chương 5:** Phân phối Xác suất Rời rạc (Nhị thức, Poisson, Siêu bội, Danh mục 2 tài sản).
- **Chương 6:** Phân phối Xác suất Liên tục & Phân phối Chuẩn (Z-score, Inverse Normal, Đánh giá tính chuẩn).
- **Chương 7:** Phân phối Chọn mẫu (Trung bình mẫu $\bar{X}$, Tỷ lệ mẫu $p$, Hệ số FPC).
- **Chương 8:** Ước lượng Khoảng Tin Cậy (Confidence Intervals cho $\mu$ khi $\sigma$ Known/Unknown - Student $t$, CI cho Tỷ lệ $\pi$, Cỡ mẫu tối thiểu $n$).
- **Chương 9:** Kiểm định Giả thuyết Một Mẫu (One-Sample Tests: $Z$-test, $t$-test cho $\mu$, $Z$-test cho $\pi$, Two-tail vs One-tail, Critical Value & $p$-Value approach).
