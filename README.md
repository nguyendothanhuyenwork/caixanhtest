# 🥬 Cải Xanh Học MAS (MAS202)

Trang web ôn tập toàn diện môn Xác suất Thống kê MAS202 (Chương 5, 6, 7) - Cải Xanh Học MAS.

## Tính năng chính
- ⚡ 20 câu hỏi trọng tâm Mas Quiz 2 (dịch song ngữ, chuẩn 5 bước, mẹo Casio fx-580VN X).
- 🧮 Máy tính mini kiểm tra nhanh xác suất chuẩn (Normal Z-score), cỡ mẫu tối thiểu ($n$), nhị thức (Binomial) và Poisson.
- 📝 Sổ tay ghi chú thông minh (Note-taking) lưu tự động trên trình duyệt, xuất file `.txt`.
- 🌓 Giao diện Dark/Light mode, tối ưu hiển thị trên cả điện thoại, máy tính bảng và máy tính.
- 🖨️ Chế độ in ấn xuất sắc sang PDF không bị đứt dòng hay vỡ công thức KaTeX.
